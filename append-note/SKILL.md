# ノートへの追記

## 手順
1. 追記先の候補を挙げる
   - すぐには書かない。作業中のフォルダ内の既存ファイルを確認し、追記先として適切なファイル名の候補を挙げる
   - 既存ファイルと新規ファイルの両方から検討し、それぞれ理由を一言添える
   - ユーザーがファイル名を決めるまで待つ（ノートの整理の仕方はユーザーが一番よく分かっているため）
2. ファイル名を指定されたら追記する
   - 既存の文章は変更せず、追加だけにする
   - 編集内容の確認方法は下記「変更の確認方法」に従う

## 変更の確認方法
- ファイルを変更する際は、先にチャット内でファイルごとに全変更内容をgit diff形式で表示して確認してもらい、承認を得てから編集を実行すること
  - ```diff のコードブロックを使い、`--- a/ファイルパス` `+++ b/ファイルパス` のヘッダーと `@@ -開始行,行数 +開始行,行数 @@` の見出しを付ける（新規ファイルは `--- /dev/null`）
  - 追加行は行頭に `+`、削除行は `-`、変更していない文脈行は半角スペース1つを付け、変更箇所の前後3行まで文脈行として表示する

## フォーマット
VSCode拡張 markmap-vscode でマインドマップ表示したときに見やすい形にする。
- 見出しは `##` のみ使う。それより下はすべて箇条書きのインデントで階層を作る
- 見出し直下の箇条書きは5行以内、その下の各階層も1つの親につき5行以内にする（マインドマップの1つの枝が広がりすぎないようにするため）
- 1項目は短く簡潔にし、階層は深くしすぎない
- インデントは半角スペース2つ

例:
```markdown
## テーマ
- 項目A
  - 詳細1
  - 詳細2
- 項目B
```
